Software

TeXLib

A LaTeX library for teaching a course. It gives you document classes for the things a course actually needs — lecture notes, problem sets, quizzes, exams, syllabi, schedules, report cards — and they all read from one coursemeta.tex, so the course number and term are right everywhere without you retyping them. Exams can generate several versions from a shared problem bank, each with a matching answer key.

If you teach with LaTeX and you're tired of copying last semester's preamble around, it might save you some time.

Repository

TeXLib-Installer

A one-click Windows installer for the above. It sets up the editor, the PDF viewer, and a full TeX Live under one folder, without needing admin rights, so uninstalling is just deleting that folder.

I wrote it for colleagues who wanted to use the library and quite reasonably did not want to spend an afternoon configuring TeX.
